# 📦 HybridBox APK Bundle Directory (`apks/`)

Place your Android `.apk` installers in this folder before running `install.bat` or `install.sh` to have them automatically installed onto your Android device via ADB:

- **`termux-arm64.apk`** — [Termux (F-Droid / GitHub Releases)](https://github.com/termux/termux-app/releases)
- **`termux-x11.apk`** — [Termux:X11 Companion App](https://github.com/termux/termux-x11/releases)
- **`termux-boot-fdroid.apk`** — [Termux:Boot (Auto-start on boot)](https://github.com/termux/termux-boot/releases)
- **`ProjectivyLauncher.apk`** — [Projectivy TV Launcher](https://github.com/spocky/miproja1/releases)
- **`SmartTube.apk`** — [SmartTube (Ad-Free YouTube for Android TV)](https://github.com/yuliskov/SmartTube/releases)
- **`Lemuroid.apk`** — [Lemuroid Multi-System Emulator](https://github.com/Swordfish90/Lemuroid/releases)
- Optional Standalone Emulators: `Snes9x EX+`, `NEO.emu`, `MD.emu`, `MAME4droid`.
